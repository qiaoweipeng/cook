# 单位统一（4 个）与单价展示调整

## Context

现在系统里的计价单位有「斤 / g / kg / ml / L」，表格里的单价还会被折算成「元/斤」。这跟实际采购口径不一致：三个平台（盒马NB、快乐猴、朴朴超市）卖的多是预包装，标价本身就是「一整份多少钱」，比如快乐猴土豆 1 kg 3 元、朴朴 700 g 5 元。

用户要的口径：
- 单位只留 4 个：`g`（克）、`kg`（千克）、`ml`（毫升）、`L`（升）。
- 单位 = 包装的计量单位；价格 = 这一整份的价格；份量 = 包装数值。
  - 例：快乐猴土豆 → unit=`kg`、price=3、amount=1；朴朴土豆 → unit=`g`、price=5、amount=700。
- 表格里直接显示「¥5 / 700g」，不再折算元/斤。
- 菜谱配料单位也只留这 4 个。
- 用户已确认：旧「斤」数据不做读取期自动换算，只认新数据（用户会自己重导 Excel）。

## 接口约定（改造后）

```
Ingredient.unit        : 'g' | 'kg' | 'ml' | 'L'
prices[平台].price     : 这一整份的价格（元）
prices[平台].amount    : 这一份的份量（与 unit 同一计量单位，缺省 1）
表格展示               : ¥{price} / {amount}{unit}
```
